# Oracle visual assets

- `oracle-logo.png`: the friendly mint O companion, generated with an image-generation tool. Original project identity, unrelated to Oracle Corporation.
- `oracle-agent-start.svg`: editable quick-start illustration for Claude Code and Codex. It shows sharing the repository URL, installing the project-local skill, and asking for a task. It illustrates the setup flow rather than a client screenshot or a guarantee of automatic installation.
- `oracle-workflow.svg`: editable workflow diagram with an accessible title and description. The developer or agent performs the work; Oracle checks recorded decisions and evidence provenance and freshness.
- The [UI examples](../skills/oracle/assets/) are editable SVG illustrations bundled with the agent skill. Recreated using [Emil Kowalski's design guidance and Oracle's task context](../skills/oracle/references/ui-design.md), they show a portfolio, small list app, and inventory workspaces using fictional content. They demonstrate hierarchy, tabular quantities, visible focus, selection, and save-state recovery. They are original Oracle illustrations, not upstream screenshots, shipped applications, or measured usability results.

All bundled assets are covered by the repository's MIT License. SVGs use system fonts and contain no scripts or external resources.

The copied upstream guidance retains its separate [MIT copyright and permission notice](../skills/oracle/references/emil-LICENSE.txt); source paths and the pinned revision are recorded in the integration guide.
