# Security

Oracle v1 reads project metadata and records supplied evidence. It is not a security scanner, sandbox, or application certification system. See [inspection and trust boundaries](REFERENCE.md#inspection-and-trust-boundaries).

If you discover a vulnerability, do not put credentials, private project content, or exploit details in a public issue. Use GitHub's private vulnerability reporting option when enabled on this repository. If it is unavailable, open an issue containing only a request for a private reporting channel, without vulnerability details.

Include the Oracle version, operating system, a minimal sanitized reproduction, observed impact, and expected behavior. Security fixes target the latest released v1 version; broader support commitments will be documented as releases are maintained.
